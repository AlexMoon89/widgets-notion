# Before / After Image Slider – Notion Widget

A lightweight, dependency-free **before / after image slider**  
designed to be embedded directly into **Notion**.

This widget lets you compare two images in the same space by dragging
a horizontal slider — perfect for visual comparisons like light/dark mode,
before/after edits, or design iterations.

---

## ✨ Features

- 🖱️ Drag slider to reveal before / after
- 📱 Works on desktop and mobile (mouse + touch)
- 🧩 No external libraries
- 🚀 Fast and lightweight
- 🧠 Easy to reuse via URL parameters
- 💯 Notion-friendly (iframe safe)

---

## 🔍 Common Use Cases

- Light mode / Dark mode previews
- Before / After image comparisons
- Design iterations
- UI or photo edits
- Focus vs non-focus states

---

## 🚀 How to use it in Notion

1. Copy the widget URL
2. In Notion, type `/embed`
3. Paste the URL and press Enter
4. Resize the embed block as needed

### Example URL

https://alexmoon89.github.io/widgets-notion/widgets/before-after-slider/index.html
?img1=https://your-image-url-1.png
&img2=https://your-image-url-2.png


⚠️ The image URLs must be **direct links** to the images  
(`.png`, `.jpg`, `.webp`, etc.).

---

## 🧩 URL Parameters

| Parameter | Description |
|---------|------------|
| `img1` | Image shown as **Before** (base image) |
| `img2` | Image shown as **After** (overlay image) |
