# Hover Image Toggle Widget

A simple Notion-friendly widget that switches between two images
on hover (desktop) or tap (mobile).

## ✨ Use cases
- Light / Dark mode previews
- Before / After comparisons
- Design variations
- Focus / Normal states

## 🔧 How to use in Notion

1. Deploy this folder using GitHub Pages or similar.
2. Copy the widget URL.
3. Add an Embed block in Notion.
4. Use URL parameters to pass your images.

### Example:
https://your-site.com/hover-image-toggle/index.html
?img1=https://example.com/light.png
&img2=https://example.com/dark.png


## 📱 Behavior
- Desktop: hover to switch images
- Mobile: tap to toggle

## 🛠 Customization ideas
- Change border radius in CSS
- Add labels (Before / After)
- Add fade speed control
- Add auto-toggle mode
